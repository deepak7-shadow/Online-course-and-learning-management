# Team Work Division

This project was built following the 4-member team breakdown from the engineering specifications:

| Member | Focus Area | Technologies & Deliverables | Git Branch |
|---|---|---|---|
| **Member 1** | **Student & Public Frontend** | React 18, Vite, TypeScript, Tailwind CSS, Lucide Icons, Supabase Auth Client. Public Landing, Course Catalog & Filters, Course Details, Student Dashboard, Video/Lesson Player, Quiz Taking Interface, Certificate Viewer, Wishlist. | `feature/student-public-frontend` |
| **Member 2** | **Instructor & Admin Frontend** | React 18, Vite, TypeScript, Recharts, Tailwind CSS. Instructor Dashboard, Course Creator & Module/Lesson Editor, Quiz Builder, Analytics Charts, Admin Platform Dashboard, User Management, Course Review & Approval Workflow, Category Manager. | `feature/instructor-admin-frontend` |
| **Member 3** | **Spring Boot Security & Admin Backend** | Java 21, Spring Boot 3, Spring Security 6, OAuth2 Resource Server (Supabase JWKS), Role-Based Access Control (RBAC), Global Exception Handler, User Profiles API, Admin Dashboard & Moderation Endpoints. | `feature/supabase-jwt-admin-backend` |
| **Member 4** | **Spring Boot Course & Learning Backend** | Java 21, Spring Boot 3, Spring Data JPA, PostgreSQL 15, Flyway Migrations. Course Catalog Service, Curriculum Module/Lesson Management, Enrollment Engine, Progress Tracker, Quiz Evaluation & Scoring, Certificate Issuance. | `feature/course-learning-backend` |
